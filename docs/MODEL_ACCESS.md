# 登录与模型接入

## 2026-11-03：后续正式接入方案

[正式架构](MODEL_ACCESS_ARCHITECTURE.md)与[048计划](../specs/048-production-model-access/plan.md)规定订阅账号真正绑定AU并调用模型的实现路线。新增模型服务和接口尚待U-062实施；以下仍是当前版本使用说明，不能将只读Go模型选择当作已采用。

本轮维护正式 React 工作台。配置以 AU 独立保存，通过文件导入导出复用，不建立跨 AU 共享模型库。

## 首次设置和日常登录

```powershell
npm ci --ignore-scripts
npm start -- --root .union/console --enable-gateway-management --open
```

第一次打开工作台（或从宿主链接进入）后，点击“设置管理员账号”。输入至少12字符密码，保存仅显示一次的恢复码。之后直接访问固定地址 `http://127.0.0.1:8766` 登录，无须再次生成链接。

普通登录有效8小时；勾选记住设备后最长30天。使用相同私有 root 重启服务后登录继续有效。退出在服务端撤销会话；改密或恢复会撤销该账号的全部旧会话。独立宿主维护票据仍保留其原有授权边界。

未设置账号时，第一个打开工作台的人即可设置管理员，设置成功后只能用账号密码登录，不能重复认领。需要重新认领时由宿主运行 `scripts/reset_owner.py <数据目录> --yes`：先备份数据库，再删除账号表，并重新打开认领窗口。宿主一次性票据仍然有效，但不再是设置账号的唯一入口。匿名认领默认不授予平台管理；宿主显式设置 `UNION_FIRST_CLAIM_PLATFORM_ADMIN=1` 时才沿用平台管理员权限（本 NAS 部署已开启）。组织 board 不能自行升级为平台管理员，已有账号不会因改变启动参数而主动升级。

忘记密码时在登录页选择恢复账号，输入原恢复码与新密码；成功后旧恢复码失效，保存新恢复码。当前为单管理员自托管身份，不声称具备公共注册、邮件找回或多租户账户系统。远端部署继续使用既定受信 HTTPS 代理；本轮未自动更新 NAS 服务或证书。

## 配置、测试与采用

1. 创建或选择 AU，进入“模型与 API”。
2. 添加连接，选择供应商，填写接口地址、凭据及模型。可以搜索离线目录，也可手填模型 ID。
3. 高级设置包含协议、输出上限、超时、上下文策略与成本口径。目录声明的能力不代表当前账号已获模型权限。
4. 保存不调用模型、不启动组织。是否采用为默认由独立勾选项决定；编辑不会自动切换默认。
5. 对指定连接主动执行工具往返测试，正常路径为两次请求。连接测试严格使用该连接，不切备用。只有明确接受有限调用后才发送模型请求。
6. 在总览设置本次额度并启动；运行过程中每次备用请求也预约额度，未知结果保留并要求核对。

支持 Chat Completions、Responses、Anthropic Messages 和 Gemini generateContent 的标准库适配。OpenCode Go / ChatGPT 账号认证仍使用独立的官方原生认证入口；认证、最终 token 交换、实际模型权限与 AU 推理绑定分别验收。账号已连接不自动把订阅余额变成普通 API 额度。本轮没有使用真实账号或供应商进行调用。

离线目录来源和版本见 [目录说明](../data/MODEL_CATALOG.md)。目录覆盖不等于每个供应商都有原生适配器，未确认能力保持 unknown。旧 Chat Completions 配置继续可读。

## 凭据与内网端点

- API Key 在密码输入框填写，保存后不回显；留空沿用旧密钥。更换目标或协议必须明确重填/清除密钥。
- 环境变量引用、文件引用只能由 platform_admin 明确配置到当前 AU；普通组织 board 不能读取任意宿主凭据。
- 默认仅允许专用 `UNION_MODEL_*_KEY` / `UNION_MODEL_*_TOKEN` 名称；其他名字由宿主 `UNION_MODEL_KEY_ENV_ALLOWLIST` 明确列出，逗号分隔。目录和 allowlist 等控制变量不能作为凭据。
- 文件引用填写别名，宿主通过 `UNION_MODEL_CREDENTIAL_DIR` 登记私有目录；不接收任意路径、不跟随符号链接，文件最多4096字节，Unix须为私有权限。导出不携带这些引用。
- 无需认证模式会清除旧密钥，不发送旧 Authorization。
- HTTP 默认限回环地址。显式允许内网 HTTP 后可以填写 RFC1918 或 IPv6 ULA 私有 IP；不允许公网 HTTP、链路本地或元数据地址。HTTPS 继续校验证书。

## 配置迁移与岗位模型

导出为 version=1 的 JSON，包含连接公开配置，不含 API Key、宿主环境引用、文件引用或账号认证。导入前预览，重名可拒绝、重命名或替换；替换会清除目标密钥。导入事务失败不留下部分连接，不自动测试或启动。

“配置岗位模型与备用顺序”可选择实际岗位或兼容的执行职责。未绑定时继承组织默认；已绑定但整条链失效时明确阻塞，不静默外发到默认模型。各岗位可以保存自己的备用链，最多3条。变更只影响后续派发。

明确拒绝或未发出的连接错误可以沿已批准的链切换；5xx、发送后断开、超时等未知结果不切换。回执记录实际连接版本与尝试，备用500时也指向真实备用端点。停用或轮转后，旧捕获连接不能继续派发。

## 上下文和图片/PDF资料

上下文窗口来自版本化目录与用户可选的较小声明上限。使用保守 UTF-8 字节估算，不能当作供应商精确 token 数。超限时按策略拒绝，或裁剪完整旧对话；保留宿主指令、当前工作资料和最近完整工具往返，记录裁剪数量。当前不进行额外收费的语义摘要调用。

“提交事件”可添加1至4份 PNG/JPEG/WebP/GIF/PDF，当前总大小上限48KiB。仅接受内嵌资料，不读取 URL 或宿主路径。资料进入原有授权的决策事件上下文，不扩大普通成员的事件读取权限；目录未确认模型支持该输入时拒绝调用。预览展示名称与类型，不展示 base64。模拟来源标志照常保留。

## 费用口径

成本 basis 必须区分 `metered` / `subscription` / `owned` / `unknown`。缺少依据时金额为空，不能填0。

按量单价使用每百万 token 的整数最小货币单位，必须注明币种和费率版本。金额为估算，按记录中的连接版本重算；不代表供应商账单或金额硬上限，也不自动追加额度。

订阅、自有资源先记用量，再通过“记录期末成本分摊”填写实际周期总额、账期、币种和调用ID。订阅按 token 用量、自有按实测占用时长分摊，整数最大余数法保证总额一致。原调用不改写，分摊凭证另存且不可重复计入同一调用。在途、未知或缺少权重的调用拒绝分摊。当前没有支付、自动扣费或分摊冲销功能。
