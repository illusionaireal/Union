## 保存位置

仓库保存部署流程、参数定义、脱敏示例和验收结果。实际主机地址、SSH 端口、登录用户名、私有部署目录及证书核对信息放在宿主私有运维记录或 SSH 配置中；密钥、口令、令牌、数据库和私人日志不进入 Git。

内网 IP 不是认证凭据，但与登录用户、端口、路径组合后会暴露具体部署结构，而且容易过期。不能把历史文档中的地址当作当前连接信息，也不能把地址可达推断为具有操作授权。连接前使用当前会话已授权的宿主配置。

SSH 示例使用本地配置的别名，不在仓库提供真实目标：

```sh
# union-nas 是占位别名，须先在宿主私有 SSH 配置中定义。
ssh union-nas /usr/local/bin/union-dev status
```

项目已有 `.env`、`.env.*`（示例除外）及 `.union/` 忽略规则。被忽略不代表自动具有私有文件权限，也不能清除之前已提交的内容；宿主仍须限制访问，配置内容不要发到聊天或诊断输出。
