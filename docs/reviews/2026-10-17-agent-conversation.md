# 009 · API 对话协议独立复核

依据 `AGENTS.md` 的资金与授权复核要求，由独立工程角色 `/root/agent_protocol_review` 只读审查。全部复现使用本地 HTTP 替身，真实供应商调用 0。

发现并关闭：

- P1：工具参数是第二层 JSON，转义凭据原先可能绕过外层检查。现在先解码再检查，之后才保存安全回复或编译；拒绝响应不触发修正，保留用量。对应秘密保护回归通过。
- P2：不完整工具参数原先无法获得修正。现在只反馈固定文字，不保存或回传未经安全解码的原文；修正仍重新预留调用并单独计量。对应回归通过。

权限与资源结论：

- 身份和版本由宿主执行记录及原始工作包绑定。模型不能提供身份、权限或版本覆盖它们，过期提议仍被事务拒绝。
- 初始化权限限定于生效章程。后续工具按岗位筛选，提交时再次检查运行时授权。
- `run`、`watch`、网页作业三入口的成功修正均复现为 2 HTTP 请求、2 条执行及 2 份用量。每次修正重新经过 `_reserve` / `_budget`。
- 单步额度、总调用额度及首次失败后试验余额耗尽均阻止额外请求。
- HTTP 503 三入口均只请求一次并保存 unknown，不自动重试。

最终针对性复验确认 P1/P2 可关闭，未发现其余权限或资源阻塞问题。此复核不证明真实供应商工具兼容性或真实模型业务完成能力。
