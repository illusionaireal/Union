# OpenRouter 云代理修复核对

日期：2026-10-18。范围：API 传输兼容、真实免费模型烟雾、旧单页清理。此记录为本轮工程自查，不冒充独立审阅或组织能力验收。

- 旧实现直接连接远端，在受管环境未读取 HTTPS_PROXY；实际 CLI 在发送 POST 前失败。修复后的新运行通过既有 `api-test`，原失败运行和占用保留。
- CONNECT 目标固定为已校验的模型 API 主机/端口，目标 TLS 继续使用标准验证和宿主 CA；不关闭验证。模型 Authorization 仍在目标 HTTPS 请求里，代理认证仅用于 CONNECT。
- 不支持的代理配置失败，不静默直连；回环 HTTP 替身不通过外部代理。没有修改角色、章程、预算或费用确认流程。
- 既有 `sent` 标记、请求截止时间、取消和 unknown 分类继续使用；未新增自动重试或恢复后自动提交。
- 凭据只沿用既有私有存储和运行注入。公开证据仅包含模型、响应、token、公开请求 ID 和费用字段。
- 直接免费模型及项目普通对话已成功。供应商 3 个生成回执总费用均为 0；项目账本继续诚实标记未知。
- 工具往返、筹建与业务质量仍未验收；其他代理协议（例如 SOCKS）本轮未支持。
