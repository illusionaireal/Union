# 048 A模型服务独立工程复核

日期：2026-11-03。独立工程角色：`review_pr12_boundaries`，未修改产品代码。主实施者根据复核意见修正代码后，复核角色重新验证；以下为其返回结论的记录。

范围：固定Go内核的账号选择、凭据刷新、单次stream；内部admin/worker与AU grant；Python outbox、当前连接/权限；平台管理员采用的跨库恢复；原生状态和React同源公开投影。费用/授权变更采用前进行了独立复核。

最终结论：限定工程范围通过，没有剩余阻断项。

- 平台管理员身份与AU使用授权分离。连接、默认绑定及采用标记同事务提交；失败不会留下半个本地绑定。
- 丢失grant回执只查询原ID。再次核对沿用original target，成功后同步原回执；重复恢复不会新增授权。
- outbox只发送一次。409冲突保持unknown，不获取并采用另一个正文的原结果；明确未接收的拒绝与未知结果区分。
- 当前权限、连接revision和grant受到检查；原生事件及凭据不直接暴露给浏览器。模型适配器为静态白名单，远端配置不能加载任意包或宿主文件。
- 订阅费用保持未知，不推定为零。原有调用预约继续生效。含modeld的运行时备用链在transport创建前拒绝，采用为默认时清空原备用链。
- 固定上游`connect()`返回`attemptID`；Go auto模式已启动callback，桥接只观察本地状态。离线认证测试重复观察仍只有一次device请求和一次token请求。

独立最终重跑：8项modeld、10项Python定向测试通过；此前还运行22项相关Python回归。内核探针有11组回环HTTP断言，覆盖双账号隔离、canonical、原生工具往返、用量、拒绝策略、幂等/单次发送、输出上限、撤销和唯一实例锁；并发显式账号读取仅产生一次上游刷新且持久化轮转结果。

真实账号访问、真实模型调用均为0。此结论不包括真实Go订阅接通、原AU业务成果、真实部署、发布或持续运行验收。整体证据见[050](../../evidence/050-model-service-engineering/README.md)。
