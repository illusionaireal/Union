## 结论

通过本批**单宿主、受控采用**复核：用户可以从 AI-UNION 的“模型与 API”页面保存 Go 认证、发起 ChatGPT 官方设备授权并查询原结果，无需作为日常配置步骤登录 SSH。该结论不表示用户订阅已经登录，不证明实际模型、额度、组织执行或长期自动调度通过。真实密钥、设备授权及模型调用数仍为 0。

采用范围包括固定私有账号后端及专用 HTTPS 工作台入口，不包括公网多租户部署或任意认证代理。原公司身份、章程、预算、工作区授权和自动调度不因账号配置入口而扩大。

## 初审问题及修复复核

1. **未知 Go 结果可通过换请求 ID 重发。** 初版已在临时夹具中独立复现：两次不同 ID 均为 unknown，却产生两次外部写调用。修复后同 provider/action 的 accepted、authorizing、unknown 状态形成持久门禁；独立复验新 ID 被拒，外部调用保持一次。显式人工核对也没有增加外部调用。
2. **未知 OAuth 缺少网页恢复，跨会话后无法核对。** 现有平台管理员可读取不含授权码/链接的待核对摘要；其他会话读取原回执时剔除敏感授权信息。用户可以在确认原设备码已取消/过期、原操作已结束后，显式记录人工核对。核对保留原状态与审计，不推定供应商未执行，不自动重发。
3. **核对请求 ID 未绑定参数。** 修复后以独立 `subscription_reconciliations` 表保存请求摘要、操作者及公开回执；相同 ID 改目标被拒，重复同参数得到原结果。重复/早退路径不回显内部操作者哈希。
4. **旧异步响应可能把设备码显示到新会话。** 新会话具有非敏感 `session_scope`，前端查询、暂存请求 ID 和本地视图据此分区；密钥在提交及范围变化时清除。提交/核对的异步响应另检查当前 scope，旧响应不能更新新会话的回执、错误或 busy 状态。已有对应组件测试。
5. **设备码进入原来不保证私有权限的 SQLite 文件。** 启用认证后要求私有服务目录 0700，数据库设置 0600；部署脚本提前创建私有 Console 目录，并采用 umask 077。摘要密钥、后端凭据和 TLS 私钥保持私有。没有把 Go 原始密钥、原始供应商异常或宿主路径写入回执。
6. **在途回调与人工核对竞争。** 本地 active 集合阻止仍在等待的回调被人工结束；更新回执不会覆盖已经 reconciled 的状态。重启保留 unknown，不恢复/重放原外部授权。原请求身份、核对及新的授权请求分别保留。

## 权限、秘密与部署边界

- 后端检查显式全局 `platform_admin`，普通 board、受限组织会话及观察者不能读取或修改宿主账号。页面隐藏不是权限依据。
- 浏览器不能提交宿主地址、认证文件路径、命令、provider 方法编号或任意目标 URL；Go 与 OpenAI 使用固定私有后端路径。后端 Basic 认证不进入浏览器或组织上下文；禁用环境代理和 HTTP 重定向，响应有大小上限。
- 官方授权链接仅允许 HTTPS 的 `auth.openai.com` / `chatgpt.com`，设备码按规定形式抽取，原始 instructions 不直接回显。模型访问状态保持 `not_verified`，保存不会启动模型或开发调度。
- 专用 TLS 入口固定为 `192.168.1.29:18766`。代理先校验 Host、Origin、Sec-Fetch，再向原 loopback Server 转发；不放宽原 Server 的来源校验。会话 Cookie 保持 HttpOnly、SameSite，并追加 Secure。
- TLS 握手位于处理线程内，最多 16 个并发连接；客户端 socket 有 10 秒超时，上游连接有超时。它们是 socket 级限制，不应称为任意慢速输入下的完整请求总期限或公网抗滥用验收。
- 匿名请求不会被代理自动授予管理员会话。原生一次性 ticket 仅写入 0600 私有 access 文件，通过既有会话交换取得权限。TLS 私钥、后端认证及用户账号认证未放入目标 Git 仓库。
- 账号后端与工作台容器不取得 Docker socket 或宿主 root；仅挂载所需私有目录及只读代码。日常 CLI 写入口遇到 managed marker 会拒绝，旧独立 Web 容器停止。

`opencode serve` 仍可能保留同根 Web 路由和完整受信维护 API，不能因为换成 serve 就宣称其 UI 被禁用。该接口仅在 loopback 提供且受私有 Basic 认证保护。禁止维护者通过 CLI、原独立界面或其他客户端与 AI-UNION 同时改写账号授权；这是受信运维约束，不是对宿主 root 的全系统强制单写入者保证。
