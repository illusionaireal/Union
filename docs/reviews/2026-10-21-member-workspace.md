# 016 独立权限复核

审阅角色：独立工程审阅 agent `workspace_authorization_review`，依据 AGENTS.md 对权限改动的要求。仅只读审阅与本地替身测试，未调用真实模型、容器或部署。

结论：可采用为默认关闭、须显式授权的工程接入，无剩余阻塞发现。该结论不代表生产隔离或公司自主开发验收。

已发现并修复：

1. Harness 工作轮的同名变量遮蔽导致崩溃，改为独立导入名称。
2. Docker 客户端退出不能证明容器停止；现在必须核对容器 State，负客户端退出码或无法确认均记未知。
3. 适配器异常及失败回执落库失败可能丢失 unknown 分类；统一保留未知状态，不重放，保留核对入口。
4. 工作区损坏、消失或产生链接时不能依赖重配置撤权；新增独立 disable，保留原绑定和未知命令回执。

审阅者独立执行 `tests.test_workspace` 与 `tests.test_workspace_harness`，16项通过，覆盖权限、暂停、幂等、中断、SDK传播与跨成员共享。主执行者另执行全量168项Python、npm检查，见 [016证据](../../evidence/016-member-workspace/README.md)。

启用前仍须在目标主机验证 Docker、受信无凭据镜像、独立工作区与磁盘配额、终止及恢复。磁盘配额由宿主提供，不是当前适配器已实现的保证；Docker daemon 为宿主信任边界。
