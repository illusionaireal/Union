# 近期交付路线：让一个 AU 交付两版真实成果

2026-11-05｜本轮路线建议。当前状态仍以[主账](../management/project.json)为准；下述里程碑、暂停模型及验收补项尚未写回，不表示未来卡已认领。

**新增能力：** S01/S05 已实现登录、创建并重开同一 AU，以及受控本地治理、撤权与责任交接。**怎么用：** 从现有 React 工作台创建 AU，在“AU准备记录”采用治理，到“责任与工作”分配内部记录工作；由人提交、治理者采用，系统校验权限并保留历史。**还缺：** V1 尚不能调用模型或让 Agent 自行交付；受控浏览器通过也不代表用户已实际验收。

## 近期用户结果与交付顺序

**创建 AU → 接入真实模型和只读工具 → 给目标 → 第一版成果 → 提交反馈 → 第二版及变化依据。** 沿现有工作台，入口与启动见[操作说明](CONSOLE.md)、[前端说明](FRONTEND.md#安装启动和验证)。首个样例：“读取我指定的资料目录，生成带文件引用的项目概览”；样例不限定 AU 的业务。

| 交付 | 用户可操作的验收 | 唯一主卡、目前状态 |
| --- | --- | --- |
| 本轮 | 配置治理、分配记录工作、提交并采用文字，再撤权或交接；系统保留原 Work/回执，拒绝失效授权。内容仍由人提供。 | S05 / U-069 / #24：代码及受控验证已有证据，真实 AI 工作未启用。 |
| 后续 1：真实接通 | 配置一个合法模型 profile、额度与只读资料范围；看到真实推理→实际读取→工具结果返回，以及用途、用量和费用未知项。只保存配置不能通过。 | S02 / U-072 / #21：V1 未交付，真实/用户验收未通过。 |
| 后续 2：首次成果 | 输入上述目标；一个 Agent 带明确责任/授权执行。工作台显示可读成果与文件引用，刷新后仍可访问；模型自述完成不算。 | S03 / U-067 / #22：未交付；最小成果展示须随本卡交付。 |
| 后续 3：反馈后再次交付 | 对第一版提出具体修改；系统采用反馈并完成第二版，用户核对变化，原成果、反馈及关联依据仍保留。 | S04 / U-068 / #23：未交付；计划或状态变化不能代替第二版。 |

本轮后预计三次结果交付，尚无可信工期。后续实际负责人均未认领；实施角色依次是模型/工具、Runtime/Harness、成果/反馈。U-072 开工前落实首个模型/profile、授权额度和工具范围；真实使用验收尚未安排具体执行者。

## 必要前置与真实验收归属

首次真实工作须具备有效治理根/章程，Member、Work、Mandate、实际 Agent Definition 版本，资源准入、当前授权/停止校验，以及失败/unknown 的原责任和请求保留。AU 持有资源、作出承诺或长期运行时，须有最终决定方、保留事项及失能处置；单主体可选预定退出（[D-01/D-04、R-01–R-07、X-02(a)](UNION_CHARTER_v1.0.md)）。

持续修章、任职交接、多层再委托和多人接班可在其功能启用前补齐；已允许的授权变化必须在后续受控行动和结果采用处生效。整卡 S05 前置是[现行工程顺序](../specs/053-union-rewrite/plan.md#4-顺序与启用门槛)，不是宪章要求；§10.2/10.3 允许分期。S05 只激活内部记录，模型/工具边界仍由 S02/S03 实现。

## 管理与决策入口

建议按“**首次真实成果 → 反馈后再次交付 → 指定窗口持续工作**”重映射 V1 里程碑。当前 12 张 V1 卡有 7 张挂旧 G0；G1“公司真实成立”也不代表准备态创建。

旧 U-007/U-041/U-044 账面 blocked、U-056/U-060 doing，本轮无人执行。建议显式历史暂停，保留 owner/blocker/history；通用执行/观察恢复分归 U-067/U-070，通用模型接入/Go profile 分归 U-072/U-075，旧开发调度与网页部署不作 V1 前置。功能承接不等于原 AU/NAS/Go 场景通过。现适配器仍把所有已开始且未 done 的任务计入 WIP，须显式增加暂停/承接语义，不能继续依赖临时增容。

看板首页展示“现在能用、下一交付、阻塞、负责人”；每张活动卡开头固定“问题、用户结果、入口、验收、当前阶段、下一责任人”，技术编号/证据放后。示例标题：“让 AU 用真实模型和只读工具完成一次往返”（U-072）。本轮提供这一页决策入口；批量改卡、里程碑和暂停模型尚未实施。
