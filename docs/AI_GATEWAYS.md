# AI 网关接入

从仓库根目录运行：

```sh
npm start -- --root .union/console --enable-gateway-management --open
```

宿主显式开启平台管理后，发起人会话侧栏显示“平台管理 / AI 网关”。不开启时，组织发起人仍可配置独立模型连接，但无权修改平台登记。已有会话需从新的宿主一次性链接重新进入；浏览器参数不授予权限。

在 AI 网关页登记已有 New API 的服务地址、API 地址（一般是服务地址 + /v1）、后台地址。HTTPS 对外访问通常是443；页面显示访问端口，不推断 Docker 内部端口。回环 HTTP 供本机服务使用。保存和刷新不会调用模型；“检测健康”只查询状态接口，健康与版本取自本次实际响应，部署状态保持未知。

在“模型与 API”中选择登记的网关，为当前 AU 填自己的令牌与模型，再预览、提交。模型工具往返测试需明确接受两次调用和费用未知，计入组织额度。登记不发放令牌，不绕过 New API 权限或厂商订阅限制。

连接保存地址快照和来源版本。修改登记不会迁移已有 AU 连接；解除登记不删除远端服务、AU 连接或令牌。需要撤销调用权限时，去 New API 后台撤销相应令牌。登记已变化的旧连接可重新选择新登记创建连接，或编辑时勾选“改为独立 API 连接”；改地址必须重新明确提供密钥。

本批支持外部接入与托管意图登记，尚无部署控制器，因而不显示启停/升级按钮。供应商渠道、订阅、路由和详细用量继续使用 New API 自带后台。真实接入和托管验收状态见 [027 证据](../evidence/027-gateway-management/README.md)及[规格](../specs/027-gateway-management/spec.md)。
