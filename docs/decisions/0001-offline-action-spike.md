# ADR-0001 · 先用离线小验证检查动作安全协议

日期：2026-10-10。状态：仅接受为 PLAN-002 预验证；生产技术选型待验证。

## 决定

使用 Node.js 24.19.0 内置 SQLite 和可直接运行的 TypeScript，避免在账号、成本与供应商未确认前引入外部调用。分离本地动作数据库与 Mock 支付数据库，以进程退出模拟“外部已成功、本地未确认”。原子预算采用 SQLite BEGIN IMMEDIATE；多进程争用测试验证当前实现的原子性。

仅允许受信任测试夹具指定的 agent/union/policy/currency/target/action。生产身份必须来自服务认证，不得从模型 JSON 自报；本验证没有网络入口或认证功能。

金额为安全范围内的整数最小单位。动作保存请求哈希与策略版本；相同幂等键不同参数拒绝。执行前预约上限；成功后结算实际成本；明确失败才释放，未知结果一直占用预算。已在执行的动作不能通过重新调用 execute 自动重发，只允许 reconcile 查询。

## 已验证与未验证

本轮证据见 npm run check 和 docs/kickoff/VALIDATION.md。Mock 服务的幂等保证是夹具行为，不是任何真实提供方的保证。

仍需实际验证：PostgreSQL 并发事务/行级隔离、Temporal Worker/服务故障恢复、真实服务幂等语义与查询能力、超时/重试上限、进程/网络沙箱、签名与凭据隔离、完整复式账本及权限复核。SQLite 不替代 PostgreSQL；子进程重启不等于 Temporal 已验收。

Paperclip：首轮独立实现 Core；当前无复制代码、无集成，也没有完成其两日复用验证。React/Web 框架、生产模型、支付、渠道和测试链保留后续 ADR。

## 停止条件

任何重复效果、越权或超额都视为验证失败；未知效果不得为赶进度释放预约。外部支出、发布及真实账户接入不属于本轮。
