# ADR-0011 持久工作意图和同一原执行

2026-11-27 编码前采用，等待实现和受控验证。依据 Main Chapter V1 D-02/D-03、P-04、R-01/R-03/R-06、FRONTEND §4.2 与在线 #76。接口、文件责任和验收见 [U-121 契约](../../specs/053-union-rewrite/u121-durable-work-intent-contract.md)。

Core 用户一次批准有限 Work 意图。在同 AU 的 GovernanceStore 事务保存批准、Work、原 attempt 和接受回执。运行时通过窄的内部已批准意图核对实际核心账户、有效治理、工作责任、资料和模型/资源版本，再复用原 WorkService、预约、封存请求、epoch 与观察和采用边界。按有效规则交付文本成果或形成带同一候选版本的决定对象。失权明确停止行动和无效采用，未决模型结果仍按原请求核对。

继续借用浏览器 token 会让普通退出影响已经批准的 Work。另建队列、引擎或成果写者会复制责任与失败恢复。用原 AU 已持久的意图作唯一事实源，让进程内提示可以丢失并从原记录恢复。首次成功采用意图显式升级 schema 7，安装预检识别实际意图特征。旧手工 Work 继续沿原合同。原输入后到时保留同一游标和预算，不用已产出的早期成果关闭它。

实际 profile、业务支出、部署、迁移和持续自治另验。原有 Core 认证、模型服务 AU grant 和当前行动资格继续适用。
