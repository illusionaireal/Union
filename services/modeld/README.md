# UNION 模型服务（048 Go 兼容与 S02 API 接入）

该服务只负责账号凭据、AU 使用授权和一次模型推理。组织目标、调用额度、成员、工具执行与持续状态仍由 Python 运行时负责。当前实现 OpenCode Go 和 `openai_compatible` 的文本与客户端工具调用路径，两者共用固定内核的单次流处理。工程测试不是供应商真实账号或真实组织交付验收。

## 固定构建与本地启动

使用仓库 Node 版本、Bun **1.4.2**。`upstream.lock.json` 固定 OpenCode 2.2.5 / `805a42f`、原锁文件、许可和补丁。上游声明的 Bun 为 1.4.4；此切片实际验证 1.4.2，构建脚本拒绝其他版本。Windows 安装了多个 Bun 时，用 `UNION_BUN` 指向选定可执行文件。

```sh
npm run build:model-service
npm run test:model-service
node services/modeld/init.mjs /path/to/private/model-service
export UNION_MODELD_CONFIG=/path/to/private/model-service/modeld.json
npm run start:model-service
```

Windows 用 `$env:UNION_MODELD_CONFIG='C:/private/model-service/modeld.json'` 设置环境变量。初始化只创建内部凭据，不读取账号或发起模型调用；已有文件不会覆盖。私有目录须属于服务运行身份：POSIX 0700、配置和凭据0600；Windows由宿主给目录配置仅服务身份可读写的ACL。目录不要放进发布目录或Git。

构建只对固定上游导出三个 Go 内核函数，补丁不改变其实现。依赖安装使用原始锁文件和 `--ignore-scripts`；补丁外的上游修改会被拒绝。文本SHA256按UTF-8/LF计算，以兼容Git跨平台换行。模型适配器采用静态白名单，不允许远端配置加载任意包或宿主文件。没有启动 OpenCode 会话、Agent 循环、业务工具、插件市场、MCP 或远端技能库。

Python控制台进程须读取同一 `UNION_MODELD_CONFIG`，浏览器继续访问原同源地址。服务只监听回环，内部管理/执行凭据分离，拒绝浏览器Origin请求。配置中的地址仅为本地内部服务，不是供应商Chat Completions地址。

## Go 兼容路径的使用与授权

平台管理员在模型页「组织模型接入」登录正式 Go 账号，在官方页面选择工作区，再选账号与模型授权给当前AU，可同时设为默认。采用操作不调用模型。设为默认时清空原默认备用链：此切片对托管模型只执行一次请求，不支持混合备用链。AU董事会继续使用现有的连接测试和有限运行操作；原有真实调用确认、剩余额度、当前章程及责任检查继续生效。平台管理员身份不等于AU成员身份。

旧4096/4097认证服务保持兼容入口。新服务持有自己私有目录内的凭据并独占刷新；本切片通过重新登录建立凭据，不复制正在使用的旧凭据数据库，不让两个运行时刷新同一凭据。

连接v2保存AU grant引用和版本，不保存供应商密钥或服务地址。导出会清空grant并停用连接；导入不能转移账号授权。使用已有grant配置连接时，宿主重新验证AU、模型、版本与撤销状态。

## S02 独立核心 API 连接

V1 核心经当前 AU 治理授权提交自己的 API 连接，不需要平台账号或 Go 账号。核心先保存原操作意图，再由内部管理凭据调用以下接口；管理凭据不能送到浏览器。

| 接口 | 行为 |
| --- | --- |
| `POST /v1/api-connections` | 精确字段为 `id, au_id, principal_id, name, base_url, api_key, model_id`。在一个 `modeld.sqlite3` 事务中保存私有凭据、参数摘要、固定账号引用和本 AU/模型 grant。保存不推理、不刷新 Go、不切默认 |
| `GET /v1/api-connections/{id}?au_id=...&principal_id=...` | 仅核对原保存；必须匹配原 AU 与稳定主体，不创建、刷新或重新授权账号 |

`id` 是原保存操作的稳定标识，`id` 和 `au_id` 沿用请求标识规则（1–160 字符，字母/数字开头，之后允许字母/数字及 `_.:-`），兼容核心实际 `org-<32hex>` AU；稳定主体 `principal_id` 使用 UUID。固定账号和 grant 引用在同一事务中分配、随原保存回执持久保留。只支持 `openai_compatible`；端点必须是 HTTPS 或回环 HTTP，禁止 URL 用户信息、查询、片段及任意请求头配置。Key 必填且最多 4096 个可见 ASCII 字符；名称最多 160 字符、模型 ID 最多 256 字符。Key 不能出现在名称、模型或其他公开元数据中。

成功返回 201，正文为 `id, au_id, principal_id, name, profile, model_id, grant_ref, grant_revision`，不返回 Key、端点或参数摘要。同 ID 相同正文返回原保存回执；不同正文（含不同 Key/端点）返回 409。相同保存操作在 grant 撤销后重放仍只返回原回执，不恢复授权；实际使用继续核验当前 grant/revision。API 账号不会出现在 Go 账号列表，也不能经旧账号模型列表或旧 grant 创建接口授予其他 AU。

保存结果未知时只查这个原 registration；核心与 modeld 之间没有全局事务，不能以重建账号、重新 POST 或按名称关联来掩盖不确定结果。API Key 只保存在 modeld 私有目录内；目录和 SQLite/WAL 文件的访问权限由服务身份控制，Windows 必须按上文配置 ACL。

每个推理请求仍只执行一次供应商流，不自动执行客户端工具或第二轮推理。原生上下文按 AU、账号、模型和固定上游配对；原生工具调用与公开参数、工具结果必须一致。输入媒体、托管工具和未支持的字段明确拒绝，不能静默降低能力。

## 持久化与故障处理

- 每个已预约run对应一个请求。Python先写outbox，服务先写inbox再发送。相同ID和正文返回原请求；不同正文冲突保持未知，不能拿旧结果结算新正文。
- 服务内单队列串行推理。单独SQLite所有权锁在恢复请求之前获取，另一个进程不能对同一目录恢复或刷新。
- 连接中断只查询同一请求，不重发POST。服务重启把已经发出的请求标为interrupted并保留原生事件；不会自动重发。
- 取消/撤销停止新动作并请求本地中止；已经收到的事件、结果和用量继续保存。取消只表达本地停止意图，不代表供应商取消、退款或零费用。
- 账号与AU授权独立。撤销接口为内部管理员 `POST /v1/grants/{id}/revoke`，正文带当前revision。提交和派发继续检查当前 grant。内部 worker 按原 AU/request 查询原始事实，不因撤权失去取证能力；凭据不回传。
- `GET /v1/requests/{id}?au_id=...` 返回原 `request_digest`、当前 `action_authorized` 和已取得的原 `result`。`interrupted`/取消结果即使存在也只能取证；不会转成可执行的 `completed`。已完成请求后来撤权则保留原状态/结果，`action_authorized` 变为 false。消费者在工具执行和接受结果前还须校验自己的 AU 治理与版本。
- 采用回执丢失时，页面的「查询原授权并完成采用」只读取原grant，再事务性保存连接和默认绑定。若连接已被其他操作修改，拒绝覆盖。完成查询也失败时，可继续核对同一个原采用请求。
- 内部 `GET /v1/requests/{id}/events?au_id=...&after=...` 支持JSON及 `Accept: text/event-stream`，按序号回放。浏览器经Python读取AU范围内的文本/工具提议投影；完整工具调用仍须通过Harness当前权限检查才执行。

服务保存原生reasoning、签名、tool-call及usage供后续上下文回放。未收到完整结束事件不交付可执行工具调用。订阅用量不当作零成本；缺少费用凭证仍为未知，期末分摊沿用现有机制。

## 升级与回滚边界

完整Python/React/modeld候选包的本地安装、原子代码切换及明确目标回滚入口已在[ops/release](../../ops/release/README.md)接入。安装器不停止运行进程，不替换业务数据；采用前必须完成现有请求核对和停机。052验证的是新临时目录中的实际构建启动与原测试登录兼容，跨版本数据库迁移及真实部署继续另验。

停止AU新派发，等待已知在途结果；未知请求保留并核对。停止旧服务后备份完整私有状态目录和AU数据库，再以新构建启动。不要让两个版本同时打开凭据目录。先检查 `/v1/runtime` 的协议及固定上游，再恢复有限运行。失败时停新进程并切回旧构建；本切片不迁移旧API连接，可继续使用原连接。

不要用旧数据库备份覆盖已经向供应商发出请求的新账本；恢复前先核对请求ID和已发生用量。部署、真实账号验收、长任务自动恢复及跨版本数据恢复演练仍按048 D独立验收；此说明不宣称发布门槛已通过。

当前范围：Go 与单个 `openai_compatible` profile 的文本/客户端工具工程路径；不支持通过此服务静默降级媒体、隐式重试/备用、组织工具托管、自动续费或新模型支出。其他 profiles、凭据池/长任务调度/资产与真实安装维护验收仍未完成。S02/U-072 的真实 profile、核心用户闭环和独立工程复核由整片验收，不能以 modeld 回环测试关闭。
