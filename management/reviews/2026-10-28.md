## 问题与决定

问题证据来自 [前次基线](../../evidence/2026-10-27-project-baseline/README.md)：状态按日期散布，旧任务与新证据容易混读；总览已有，但状态仍靠手工维护。目标是让后续维护者能找到当前任务、责任、依赖和实际验收程度。

决定先采用仓库 JSON 主账、自动生成的 Markdown 总览/看板和现有 CI 校验。原因是本项目当前就在 Git 内协作，可复用版本记录与已有检查，无新增账户、服务或费用。暂不接 GitHub Projects 或另购系统；实际多人协作需求超过这套方式时，再按工具决策模板比较，保留编号与导出路径。不是对未来工具的永久限制。
