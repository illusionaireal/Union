## 冻结行为

1. 只有构造请求前失败或 POST 明确返回既有确定拒绝状态才抛 `Rejected`，保留当前零调用行为。
   POST 已接受后的回执身份、事件顺序、结果格式错误属于待核对，不能声称未执行或释放占用。
2. modeld 的原请求 ID/AU 匹配、状态 completed、结果结构完整，但当前授权为 false 时，通道返回独立的不可采用完成事实。
   事实仅含原请求 ID 和非负整数 token 用量（bool 不算整数）；不转交模型正文、工具请求或私有原生上下文。
3. 同一 GovernanceStore 事务记录本次 step、原模型 request ID、`used`、已知 usage、未知费用和不可采用原因。
   不创建结果、不执行工具、不标记 Work 完成。命令 succeeded 仅表示事实记账成功，`model_outcome=not_adoptable` 明确业务未成功。
4. run_loop 遇到不可采用完成事实立即停止，返回 rejected / not_adoptable；完成的一次推理计入 turns 与用量。
   正常 completed、派发前拒绝和未知调用分别保持原行为。重启及原回执查询保留事实；不能把 used 改判为 released。
5. 不新增公开写命令或迁移；沿既有 schema 3 的 step 扩展观察字段，GovernanceStore 仍是唯一写者，原审计字节不改。
   权限/计量改动须另一工程角色复核后采用；本次只交草稿候选。

派发前持久化预约/并发治理或身份变化期间的原请求归属属于评审项 1，须另行冻结共享事务后修复；本子项不声称解决该竞争窗口。

## 验收

- 原三项独立探针在真实最新 head 均 RED；本子项完成后第三项 GREEN，前两项保持明确未完成。
