# 027：New API 网关接入与观察

2026-10-30，用户确认开发。平台公共接入与 AU 组织运行分开；本批 U-037 实现第一批，运维控制为第二批 U-038，真实集成为 U-039。

## 范围与权限

平台登记 New API 的名称、服务根地址、API 根地址、后台地址和 external/managed 模式；存 SQLite，全局请求回执保留。宿主通过 `--enable-gateway-management` 为一次性 board 启动链接显式授予 platform_admin；普通全局 board、受限 board、observer 和成员没有此权限。全局平台管理不能借组织权限推导。此选项是当前本机受信模型，不是公网多租户账户系统。

组织 board 可在自己可访问的 AU 内选择平台公开登记的网关。登记是公开连接目录，不是令牌发放或消费授权系统；AU 自己保存令牌，实际调用权限由 New API 校验，组织预算继续约束调用。平台不复制上游凭据、不代管 New API root 登录、不自动开户/充值/购买订阅。登记配置对可访问组织的 board 可见，不提供给观察者/成员。

AU 保存公开地址快照和 (gateway_id, revision) 来源；配置、默认绑定和工具往返测试复用现有命令/回执。更新登记不会自动迁移 AU 连接或携带旧密钥到新地址；解除登记仅影响目录，历史和 AU 现有独立连接保留。撤销已发令牌须在 New API 执行。编辑旧来源可重新选择新登记，或显式改为独立 API 连接。

## 接口与状态

- GET `/api/gateways`：平台管理列表及最近20项回执；带 organization_id 时仅返回 id/revision/name/api_base_url 公开目录，服务端校验 AU board 范围。
- POST `/api/gateway-commands`：{id,gateway_id,base_revision,kind,data}；kind 为 save/archive/probe。乐观版本、幂等请求标识、持久回执；GET `/api/gateway-receipts?id=...` 查原回执。
- 健康检测为显式 POST 启动的只读作业；普通 GET/自动刷新不探测、不调用模型。不发送凭据、不跟随重定向、响应限64KiB、socket操作超时2秒，固定模块子进程总时限4秒，超时终止并回收，包含 DNS 与慢速响应；同实例一个在途检测，全局最多8个。宿主代理沿用现有设置。仅读取 `/api/status` 的 success/data/version，远端正文和异常细节不公开保存。
- health 为 unknown/healthy/unavailable，附检测时间；部署状态始终 unknown。健康不代表模型可用，无法连接不代表已停止。接口不返回版本时显示未知。旧登记或旧检测的响应不覆盖新结果；宿主中断的 accepted 回执改 unknown，不自动重放。
- 外部链接仅允许无认证/查询/片段的 HTTPS 或回环 HTTP，并使用新窗口隔离。宿主管理员显式配置探测目标；本服务不是公开 URL 探测代理。

## 明确不在本批

尚不执行安装、启动、停止、重启、更新、备份、恢复；managed 仅登记意图，无控制器时 capabilities 为空且不提供这些操作按钮。第二批需固定服务对象的 Docker Compose 适配、持久运维任务、在途影响处理、备份/迁移/恢复和独立权限复核；不接受任意宿主路径或 shell 命令。

## 验收

1. 实际 HTTP 和受控 New API 状态替身覆盖权限、来源、探测协议、无重定向、响应限制、版本未知、离线状态、重启恢复、幂等和并发旧结果。
2. AU 在有效组织范围内保存来源快照和私有令牌；其他组织/观察者不可读密钥；登记迁移不改原地址，编辑迁移仍要求重新提供密钥。工具测试沿用两次调用、费用确认和资源计量。
3. React 测试及实际浏览器验证登记/检测/编辑/解除和模型页选择，含移动端；npm check 和 Python 全回归。
