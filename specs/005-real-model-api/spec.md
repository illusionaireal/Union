# 005：真实模型 API 执行链路

2026-10-13。用户授权完成后端升级并提交代码，前端由另一位同事实施。

- 支持可配置的 OpenAI-compatible Chat Completions API：Base URL、模型、密钥、结构化输出模式、输出上限和超时；不依赖 Codex CLI。
- 组织绑定默认连接，单次运行可选择连接；运行固定配置版本。密钥只留在组织私有数据库，不能进入正式状态、事件、命令载荷、回执、工作包或执行文件。
- 提供现有受信 HTTP 命令与 CLI。配置不调用模型；连接测试明确接受未知费用，预约一次调用并留存用量，不改变组织结构或消费业务事件。
- 调用无自动重试、无重定向。超时、连接中断和 5xx 的远程结果未知，保持占用并核对；明确拒绝和无效结构化结果分别记录。
- 模型输出经协议校验及现有身份、章程、版本校验后提交。记录实际模型、供应商请求标识、耗时、token、未知费用及配置版本。
- 真实 API 纳入 E1/E2 评估；fixture、回环 HTTP 替身和连接测试不构成真实组织验收。
- 前端源码、生成 HTML 和历史证据不在本次修改范围。金额硬上限仍不受支持；采用授权实现前按 AGENTS.md 独立复核。

验收：密钥不回传、权限和版本冲突拒绝、配置持久化与绑定、HTTP 请求与输出限制、拒绝/坏响应/超时/不重试、连接测试额度、CLI 与工作台一致性、完整 HTTP 替身闭环和模拟标识。真实供应商验证需要用户配置的密钥与有限资源，缺失时如实留下待验证项。
