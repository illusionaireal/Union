# 052：模型服务候选包与离线版本切换

接续048 A / U-060的可安装交付，供U-054后续发布验收复用。真实账号和AU成果/反馈尚待资源；本切片不关闭048 A或U-054。

## 需求与实现边界

- 同一候选ZIP包含实际Python运行时、已构建React工作台、固定OpenCode模型服务、依赖锁及上游许可；只收集明确允许的发布文件，不收集未跟踪历史文件、凭据或业务数据。
- 清单记录Git基线、每个源文件和发布文件SHA256、模型服务上游及工具链。工作树改动如实标记，不冒充干净提交构建。摘要用于完整性检查，不替代可信分发或签名。
- 安装先检查整个包，再写入新的版本目录；不覆盖已安装版本。损坏、重复、路径穿越、链接和额外文件必须拒绝。失败不更改当前版本。
- 安装目录、Console业务目录和modeld私有配置必须显式配置并相互隔离。安装和版本切换不停止服务，不改凭据，不备份覆盖业务账本，不触发模型调用。
- 当前版本使用原子替换的小型指针文件。切换前验证目标文件及宿主Python/Bun；失败保留原指针。回滚只切换代码到明确指定的已安装版本，保留最新业务数据和未知请求。
- 版本操作互斥；旧操作锁不自动删除。运维方停止旧进程、确认无在途写入，再切换并按现有说明启动。运行中自动切换、跨版本数据迁移、真实NAS部署及完整备份恢复另验。

## 验收

行为测试覆盖损坏包、目录逃逸、额外文件、安装冲突、坏目标/失败预检不切换、互斥、回滚保留数据。使用实际构建在新临时目录安装、启动Console与modeld、切换另一版本并回滚，固定地址登录前状态和空账号服务可查；真实模型调用0。
