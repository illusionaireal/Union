# 004 组织操作工作台

日期：2026-10-11（北京时间）。来源：用户明确说明产品应是可操作的前端界面，而不止 Dashboard。优先级 **P0**；取代此前“首版网页仅只读”的产品范围选择。003 保留为其中的观察模块。

状态：需求与操作原型阶段；真实前端读写服务、运行控制与授权会话尚未实现。原型的模拟操作不调用模型、不写组织数据库。

## 产品目标

发起人可在浏览器完成“创建并采用 → 启动有限运行 → 查看协作与成果 → 暂停与调整 → 处理异常 → 继续运行”的主流程。CLI 保留为辅助与恢复入口，普通操作不要求用户转到终端。

## 必需操作

| 编号 | 用户行为与结果 |
| --- | --- |
| O01 创建与采用 | 填写组织名称、目标、采用人、受支持章程正文与字段、调用上限及单次超时，预览后创建独立组织。不得覆盖已有组织；创建不自动启动模型。服务分配组织 ID 与存储位置，浏览器不传任意本地路径。 |
| O02 启动／继续 | 选择已配置执行器、本次有限步数及必要的等待窗口，显示累计占用、剩余资源、单次超时与费用状态。真实 Codex 的费用未知须在操作界面明确选择接受；服务器重新校验权限、配置、额度和现有执行状态，受理不等于执行已完成。 |
| O03 暂停派发 | 发起人请求停止新的派发。若有在途执行，状态为“暂停已请求，等待在途结束”；收到可确认回执后才显示暂停生效。远程取消未确认时进入未知结果核对，不能显示全部已停止。继续运行须重新检查原额度与状态。 |
| O04 提交事件 | 提交意见、事实或外部反馈，填写内容、来源和模拟标记；服务分配／核对事件 ID，重复提交不重复写入。事件进入组织决定循环，不直接改写任务或强制成员结论。 |
| O05 资源设置 | 查看并修改总调用上限及单次超时，展示新旧值、已占用额度与调整理由。不得清空历史用量；资金费用未知时不能伪造金额硬上限。运行中不悄悄修改条件，先完成暂停或返回明确的可重试状态。 |
| O06 章程修订 | 通过受信董事会会话修改支持的正文与规则字段，查看差异、基准版本与生效影响，填写理由后提交。遵守旧章程的修订权限；权限收缩对待办和在途的影响明确显示，不允许仅编辑正文就隐式扩大工具权。 |
| O07 执行核对 | 对已确认 unknown 的指定运行记录，查看来源与回执，填写核对依据，选择“确认未执行”或“放弃本次执行”。不能对活性未确认的 running 盲目重派；核对不退调用占用、不自动重试，已有成果暂不自动导入。 |
| O08 操作回执 | 每项操作展示目标组织、类型、请求标识、操作者、提交时间、基准版本及受理／处理中／成功／拒绝／结果未知状态。超时先按原请求查询结果，不直接再发一次；拒绝原因及版本冲突可读，取消预览不发生写入。 |
| O09 角色与会话 | 发起人／董事会角色由服务端受信会话确定；观察者能查看但不能写入。按钮状态提供说明，接口必须独立检查权限。董事会密钥、认证材料、任意路径及私有日志不进入 HTML 或请求体。 |

## 操作与观察边界

Dashboard 的读取、筛选、刷新、查看与下载继续只读，满足 003 的 D01–D09、A01–A10。写操作通过明确命令入口，不能由刷新、GET、页面加载或查看详情触发。所有命令校验组织范围、身份、权限和基准版本，保留审计，并可按幂等请求标识追踪。

本地也需要受信操作会话；服务端限制来源与访问边界，不能把“监听 localhost”当作免鉴权的管理接口。首版不要求多用户账号平台，但角色权限须真实执行。公开远程部署另需相应访问控制。

发起人通过目标、章程、资源和事件治理组织。当前不增加任意覆盖成员安排、直接写正式任务或无条件重新执行的按钮；相关管理能力以后仍须遵守岗位与章程规则。

## 现有能力与新增开发

| 能力 | 当前复用入口 | 待实现 |
| --- | --- | --- |
| 创建采用 | Engine.create / CLI init | 表单、受信会话、独立目录分配、命令回执。 |
| 有限运行 | runner.run / watch | 服务端作业管理、运行活性、请求追踪、重复启动防护。 |
| 暂停派发 | 当前没有跨进程暂停协议 | 持久暂停意图、派发边界检查、在途回执及未知结果处理；不能用页面布尔值代替。 |
| 事件 | add_event / CLI event | 来源校验、幂等接口、表单与回执。 |
| 资源／修章／核对 | configure_resources / amend / reconcile | 服务端受信身份、版本冲突与原锁约束处理、预览提交及审计。 |
| 观察 | status / events / decisions / usage | 按 review 修订活性与一致快照；前端刷新序列与断开恢复。 |

## 验收

| 编号 | 必须通过的行为 |
| --- | --- |
| C01 | 在浏览器创建组织，校验失败保留输入；取消不创建；重复提交只生成一个组织，原组织不覆盖。 |
| C02 | 从网页运行完整 fixture 协作闭环并查看成果、额度和回执，用户无需 CLI；启动真实执行器的表单选择不代表已有真实能力验收。 |
| C03 | 慢执行器在途时暂停，后续不新派发；暂停状态只有在服务器确认后推进；未知结果不误报已停止、不自动重试。 |
| C04 | 改资源保留用量；修章按旧权限与当前版本生效。版本冲突、额度不足、身份失效、并发运行均清楚拒绝，无部分写入。 |
| C05 | 观察者绕过禁用按钮直接调用写接口仍被拒绝；未授权会话和不允许的请求来源不能写入；返回内容不含凭据。 |
| C06 | unknown 核对有依据、处理指定运行且不返还调用量；running 活性不足不能跳过核对程序直接重派。 |
| C07 | 命令重复、连接超时及晚到回执通过同一请求标识查询，操作只生效一次；取消预览或刷新页面不触发新写入。 |
| C08 | 事件含来源与模拟标记，重复事件不重复产生后续行为；系统意见与真实市场反馈明确区分。 |
| C09 | 桌面与手机完成主流程，表单错误、待处理、成功、拒绝、断开及版本冲突可理解；观察模块 A01–A10 和核心回归通过。 |

产品定义见 [PRD](../../docs/PRD.md)，交互见 [产品设计](../../docs/product-design.md)。原型可用于评审操作流程；以上 C01–C09 必须由真实服务与浏览器另行验收。
