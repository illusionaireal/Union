# 操作工作台实施计划

先用 PRD v0.2 和操作原型确认页面行为，再连接实际组织服务。此次范围调整不授权在聊天中自动开始真实模型或对外发布。

1. 合并工作台信息架构：保留六个观察视图，增加组织设置与操作回执；创建、启动、暂停、事件、资源、修章和核对都有可完成的表单流程。
2. 实现本地受信会话与服务端动作权限；为读取与命令使用独立路由，绑定组织范围、操作者、基准版本和请求 ID。密钥保留在服务端，不允许浏览器自报 board 身份。
3. 在一致只读快照上接入 003 观察模块，继续修正正常在途误报、同版本更新与乱序问题。
4. 将现有 Engine 操作包装为受信、可审计、幂等命令；对先读取再修改的操作，在同一受控执行边界检查基准版本，防止 TOCTOU。
5. 新建服务端运行管理和暂停协议：启动只受理一次，记录活动执行与暂停意图；派发前检查停止条件，等待在途回执。记录未知执行后必须核对，不用进程杀死事件推断远端取消。
6. 处理现有 CLI exclusive 锁：管理变更在可安全提交时执行，否则明确返回运行中／需暂停；不允许绕过原锁修改在途组织。必要的内核适配先有行为测试。
7. 实现实际前端提交、预览差异、错误与冲突、回执轮询和断开恢复；现有单 HTML 原型中的模拟模型全部替换为真实接口，不保留模拟成功回退。
8. 用浏览器操作实际 fixture 验证 C01–C09 与 A01–A10，保留 `evidence/004-organization-console/`；真实模型试跑另行记录。

本迭代不把原型按钮当作功能实现证据，CLI 通过也不等于网页权限或幂等已通过。
