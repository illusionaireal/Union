# 005 · 工程化组织工作台

日期：2026-10-13。用户明确要求以 React + TypeScript + Vite 交付完整前端工程；本规格接续 004 的实际服务与 003 的观察模块。

## 产品边界

正式工作台为 SPA，保留总览、成员与岗位、工作、成果、活动、执行与资源、组织设置七页及 004 全部操作。目标、成员和工作仍由运行时决定，不预设行业模板。页面使用中文，桌面侧栏、移动端可滚动导航；模拟来源明确显示。路由可直接访问、刷新和浏览器前进后退。

继续使用 Python、SQLite、一次性本机会话及现有 `/api/*` 契约。静态产物由 Python 同源提供；无需额外生产前端服务。首次 `npm ci` 后，`npm start -- --open` 一条命令构建并启动。原 Python 入口保留，读取已有构建。单 HTML 设计演示和报告保留，历史实际前端源码归档供追溯。

## 工程和验收

- React Router 管页面；TanStack Query 管读取、取消、轮询和缓存；命令无自动重试。
- 页面、公共组件、API 类型/客户端、命令表单/回执、详情分别维护。严格 TypeScript，锁定依赖，CI 类型检查、测试和生产构建。
- 会话绑定服务实例；快照按组织、分页隔离，取消过时请求，不能用组织状态版本丢弃同版本的新执行记录。断连保留过期快照、禁止写操作。
- 表单编辑不被轮询覆盖。提交前预览、校验当前组织/版本。未知结果只查询原请求；终态回执不能被晚到错误降级。
- 复用已有真实 HTTP/Chromium 验收，新增路由刷新/前进后退、输入与焦点保持等迁移检查；浏览器测试仅用 fixture 与执行器替身，真实模型调用 0。
- 静态路由、路径边界、CSP 与未知资源 404 有后端验证。API 的权限、会话、来源校验保持现有契约。

Sites、Figma、Canva 当前会话无可调用工具。此限制不阻碍仓库工程交付；不声称已经创建 Sites 站点或完成外部发布。
