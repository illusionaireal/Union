# 010 · 组织筹建与成员 Harness

用户于 2026-10-17 确认实现：临时筹建 Agent 建立组织，复用普通 Agent Harness 完成成员工作。开发主线 dev。

## 行为

- 初始目标、章程、预算及模型配置由宿主保存。筹建身份只在 bootstrap 阶段有效。
- 筹建 Agent 可以分批保存、查看、修正成员和任务草案，再请求成立。草案不是正式任职或任务；成立时至少两名成员、协调责任和可执行工作一起事务提交。
- Deep Agents Python SDK 为默认 API 成员执行底座，LangGraph SQLite 检查点保存任务会话及虚拟工作区。岗位身份和正式状态继续由 UNION 管理。
- 模型 -> 工具 -> 工具结果 -> 模型使用 SDK 图循环。每次派发最多一次 HTTP 请求；工具节点完成后暂停并保存，下次派发恢复，不要求每次模型回答符合整包 Schema。
- 有限运行的步数仍代表实际模型请求上限。进度调用逐次结算 token，未交付的工作保持可继续，不能把工具过程或筹建草案标成成果。
- 工具每次使用当前宿主身份和授权；章程/任职/任务版本变更不得恢复旧权限。关闭框架默认临时子 Agent 和隐含模型摘要调用；跨成员派发、用量和授权经 UNION。
- 请求失败、截断、未知执行不自动重发。未知结果仍需核对；检查点不能被视为外部动作恰好一次的保证。
- 普通连接探测保留；新增受预算约束的工具往返测试，验证调用工具后能够读取结果继续回应。测试不建立组织。
- 网页显示筹建草案和可继续进度；CLI 与网页使用同一 Harness。旧组织及 fixture/Codex 路径继续可读取。

## 验收

真实 SDK + 本地 HTTP 替身验证分批筹建、局部修正、跨进程恢复、真实工具往返、两成员成果依赖、逐次额度与用量、暂停/修章/未知不重派、秘密不进入检查点。真实供应商及正文质量单独验收，不以 HTTP 替身代替。

## 选型

选择 deepagents 0.7.28，langgraph-checkpoint-sqlite 3.1.2；通过自定义 BaseChatModel 复用已经校验的 Chat Completions 传输和 token 参数，不使用供应商 SDK 的隐式重试或参数改写。对照 LangChain create_agent 使用相同受控模型和工具验收通用回环。当前不引入云端 Agent 服务、Temporal 或新的业务数据库。
