# 010 实施计划

1. 固定 SDK 依赖与可重建安装；封装普通消息传输，保留原适配器回归。
2. TDD：草案持久化、成立校验、进度结算、会话绑定及额度。
3. 以 SDK 工具节点检查点作为单次调用边界；虚拟文件只在任务会话中，组织写操作走既有 Engine。
4. API 启动默认 Harness；新增工具能力探测，展示筹建与恢复状态，统一启动安装和 CI。
5. 权限/资源独立工程 review，完整机制与前端检查、HTTP SDK 回环和必要浏览器验证；记录真实模型缺口。

模型服务密钥未由本次任务提供。只读取实际配置是否存在；不从无关项目或环境提取凭据。无可用连接时保留真实验收未完成，工程实现继续完成。
