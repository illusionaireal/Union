# 048：正式大模型接入

2026-11-03。用户要求：为UNION设计真实可用的大模型接入，能力不低于OpenCode与Hermes，不交付测试、模拟或仿真产品。

## 目标

用户在现有React工作台连接账号或API，选择模型并采用到AU；组织初始化、员工工作、工具调用、成果和反馈后的后续行动均使用该真实连接。现有订阅只读卡片必须成为可使用的入口。

采用[正式架构](../../docs/MODEL_ACCESS_ARCHITECTURE.md)：保留Python组织Harness，新增基于固定OpenCode模型/认证内核的`union-modeld`；单次推理与UNION工具执行分开。Hermes凭据池及恢复能力作为对标要求。New API为可选连接。

## 必须交付

1. 已授权Go账号→真实模型→AU采用→实际业务工具→成果→后续行动完整可用，接续ChatGPT及API路径。
2. API Key、受限env/file、OAuth续期/撤销、云身份、自托管；账号与AU使用授权分开。模型选择可持久化，真实路由在请求记录可查。
3. 原生流式、多工具往返、推理/签名/opaque状态完整回放、模型参数及缓存正确处理。
4. 岗位/任务/辅助用途路由，多凭据轮换、配额排队、明确备用顺序；没有静默使用其他账号或计费来源。
5. 长任务不被短HTTP总超时截断，事件持久化、刷新续看、请求查询、取消意图和远端结果分别表达。
6. 推理未决、动作未决、费用未决分别恢复；业务工具幂等、迟到attempt隔离、每次网络重发独立预约。
7. 上下文压缩与文件资产可用于实际工作，费用basis、真实用量、估算与账单核对清楚。
8. 固定构建、安装升级、数据迁移和回滚；更新正式使用指南。权限与费用实现采用前按AGENTS要求独立复核。
