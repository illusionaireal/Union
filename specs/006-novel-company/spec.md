# 006 · 一家开箱即用的 AI 公司

2026-10-15 用户确认：开发主分支为 dev。Q1–Q3、Q5–Q6 接受，Q4 最小兜底。

- 网页创建小说公司，提供目标、初始模拟预算，采用可查看的默认章程；网页配置、绑定、测试真实模型 API 并启动。
- 同一本小说连续三章，三个经营周期：组织计划、创作、提交 mock 平台、模拟订阅结算、核算、决定下一步。无需逐章人工派发。
- 题材、设定、岗位、成员（至少两名）、任务和审核由模型决定。宿主仅提供业务动作和实验终点，不预置创作流程。
- 平台规则版本固定，第二章受控低订阅反馈；成员不能更改规则、定价或账本。第三章必须由反馈后的计划推动，保存反馈→决定→工作→成果证据。正文质量和改变落实由人工验收，不从 mock 订阅推断。
- CNY 整数分账本：初始资金、订阅收入、服务器/税费是模拟；模型输入输出 token 来源于调用回执，按创建时填写的每百万 token 单价估算。fixture/回环服务用量另标模拟。未知用量保留未知，不能当零成本。
- 预算余额到限停止新调用（估算经营阈值，不是供应商账单硬上限）；保留进度/错误，人工继续；unknown 沿用核对机制。不开复杂自动重试。
- 幂等投稿、原子结算、章程与岗位授权、董事会配置、密钥不回传/持久化到浏览器、只读快照必须保持。
- 自动化机制验收与真实供应商/章节人工验收分开报告。无密钥时完成可重放演示但不宣称真实自主经营成立。
