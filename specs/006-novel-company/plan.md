# 实现计划

复用 Engine/Runner/Console/React；新增独立 company 业务模块，只在选定小说试验时启用。

1. 首版公司配置与业务状态嵌入组织持久 state；无需迁移既有数据库。
2. submit_chapter / review_cycle 为受章程和岗位授权的决定操作。宿主校验真实成果、顺序与同书标识，固定 mock 规则并原子记账/发反馈。后续投稿须等上一轮复盘；反馈优先于既有待办。
3. 执行结算记录 token 估算，预算判定停止新派发。三轮复盘后停止本次试验。
4. React 新建小说选项、API 配置/绑定/测试、经营卡片及证据链接；沿用命令回执和预览，不保存密钥到浏览器存储。
5. 关键机制 TDD、HTTP/浏览器端到端验证、原工程回归；依据 AGENTS.md 由另一工程角色复核资金与权限变更。
