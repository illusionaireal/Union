# 002 开发进展展示网站

用户明确请求：使用 Sites/Cloudflare 建立网站，展示当前开发进展、简单演示和系统架构。

用户后续要求将运行 Dashboard 纳入项目必要组件，详见 [003-runtime-dashboard](../003-runtime-dashboard/spec.md)。本展示网站继续作为开发进展快照；其已完成状态不代表 Dashboard 已实现。

## 已实现

- 中文响应式静态页面：实际工程状态、验证结果、尚未验证的能力与下一步。
- 公开验证快照导出，不接入数据库、董事会凭据或私有日志。
- 基于已验证 fixture 的七阶段协作重放，支持播放、暂停、前后步、阶段跳转与重置。
- 三份模拟成果可读取、切换及下载；来源和模拟性质清楚可见。
- 六模块交互架构图，展示职责、数据流与当前实现边界。
- Cloudflare Pages 静态交付目录、同源 CSP、部署脚本与 Direct Upload ZIP。
- 根据用户后续要求交付单 HTML：内置全部资源、公开快照和可下载成果，运行时无需外部文件。

## 实际验收

- 37 项 Chromium 浏览器检查通过，包含交互、键盘、CSP 和 4 种屏幕宽度。
- 本地静态 HTTP 服务中的交互已验证；云浏览器禁止 file 导航，直接文件打开未验证。
- 原 25 项机制测试回归通过，真实模型调用数维持 0。
- 页面不承诺实时状态、真实模型自组织、经营发布或外部反馈。
- 单文件通过 43 项断网 Chromium 文档检查，成果与验证摘要实际下载成功，网络请求 0；直接 file 导航仍未验证。
