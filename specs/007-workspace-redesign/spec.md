# 007 · 通用公司工作台与模型连接

2026-10-16：用户明确要求整体优化前端，而非仅增加小说公司特化面板；模型 API 必须有清晰可用的入口。

- 所有现有组织使用统一的新工作台，包含总览、团队、工作、成果、活动、模型与 API、执行与资源、治理与设置；小说试验是可选业务场景。
- 空实例和已创建但未运行的通用组织都展示明确的建立公司、连接模型、启动协作流程。模型入口始终可发现；无组织时说明连接按组织保存，并提供创建入口。
- 独立模型页面读取已保存连接，展示名称、地址、模型、密钥是否配置及默认状态；支持新增、编辑、设为默认、解绑和一次连接测试。使用现有受信命令、预览和回执，不新增权限机制。
- 新增连接不得默认覆盖已有连接；编辑预填公开配置，密钥不回显，留空沿用现有密钥。测试与运行分别确认有限真实调用；保存不调用模型。
- 桌面和 390/320px 页面可用；键盘、刷新、组织切换、断线、观察者权限和未知结果恢复继续成立。
- 真实模型调用仍为 0；页面和回环模拟检查不证明真实组织能力。

验收：A01 旧通用组织可看到新版首页；A02 无组织可找到模型入口；A03 新建/编辑/默认切换/解绑实际持久化；A04 模拟连接测试与有限执行闭环；A05 密钥不泄露、无自动调用、切换不混用配置；A06 全页面导航、手机、键盘及现有组织回归。
