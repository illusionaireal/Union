## 范围与方法

`scripts/u125-organization-entry-browser.cjs` 使用构建后的 React 页面、Chrome/Playwright 和 `tests/model_access_browser_host.py` 的可重启回环 HTTP 服务。首次账号建立、普通密码登录、第二个独立主体、目录、准备态 AU、创建回执和重启来自真实本地认证/HTTP/持久化实现。

脚本仅通过现有五字段 `POST /api/commands` 显式建立四个隔离夹具：一个用于证明旧目录隔离的 legacy 记录、同一主体的准备态 A/B、另一主体的准备态 C。没有模型连接、业务执行或资源授予。夹具不是 U-126 创建表单验收，不证明完整 V1 自主业务。

故障注入逐项标识：浏览器断网、AU 403、延迟原 AU 响应、会话主体/服务实例/401、目录移除、最近访问存储不可用。两个主体的登录和直接 HTTP 越权拒绝不使用响应替身。注入的会话变化不代表真实账户或治理权限已变更。

每次运行创建独立临时数据目录；截图、请求路径计数与检查结果保存在被忽略的 `.union/u125-organization-entry/<UTC运行时间>/`。不输出或保存 host 启动 ticket、账号恢复码、Cookie、请求 payload 或私有看板凭据。截图不包含账号建立/恢复界面。

```powershell
$env:PYTHONUTF8='1'

```
